# Dossiê de Provas

Levantamento de olimpíadas, vestibulares, colégios militares e concursos de nível médio abertos a
quem está no ensino fundamental ou médio no Brasil — feito em 15/09/2026 via pesquisa web (WebSearch +
WebFetch, abrindo as páginas oficiais de fato, não só confiando no snippet do buscador).

A versão editada e publicada (com a lista final já corrigida e organizada por seção) está em:
**https://claude.ai/artifact/FwiQ93VBD57oNWfi1qjZt5** — também salva aqui como [`dossie-provas.html`](dossie-provas.html).

Os arquivos `01` a `11` abaixo são o material **bruto** de cada frente de pesquisa (uma por agente
disparado em paralelo), com todo o detalhe, incerteza e nota metodológica que não coube na versão
final — inclusive os erros que a pesquisa corrigiu em relação ao levantamento inicial (ex.: organizador
errado de uma prova, sigla que não existe, olimpíada extinta). Preservados como fonte de verdade caso
seja preciso atualizar o dossiê publicado depois.

## Nota metodológica geral

Boa parte das bancas e organizações brasileiras **não mantém um índice único** com os aprovados/premiados
de vários anos — cada edição vira um PDF avulso, um post de notícia, ou fica atrás de login. Vários
domínios oficiais (`.mil.br`, `.gov.br`, e alguns `.org.br`) bloqueiam acesso automatizado (Cloudflare,
WAF, certificado quebrado) mesmo abrindo normalmente num navegador comum — isso está sinalizado item a
item. Onde nenhuma fonte confiável foi encontrada, o campo diz "não encontrado" em vez de um link
chutado.
